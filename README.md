# Shape Survivor Hands-on

Zennの書籍「ゼロから始めるGodotゲーム開発 〜作って学ぶ「Shape Survivor」〜」に対応するハンズオン用リポジトリです。

## この本について

- **対象読者**：Godotエディタに触るのが今回はじめての方
- **題材**：自動で攻撃しながら押し寄せる敵を生き延びる、ヴァンパイアサバイバー系のミニゲーム「Shape Survivor」
- **方針**：画像ファイルは一切使わず、すべてコードと単純な図形ノードだけで表現する
- **構成**：全12章。各章は必ず「実際に動く状態」で終わり、章の最後に自分の手で動作確認する

書籍本体は以下から読めます。

- 📖 Zenn: [ゼロから始めるGodotゲーム開発 〜作って学ぶ「Shape Survivor」〜](https://zenn.dev/yurinchi/books/01ecd492dc6adf)
- 🎥 YouTube: [おやこでペアプロTV](https://www.youtube.com/@%E3%81%8A%E3%82%84%E3%81%93%E3%81%A7%E3%83%9A%E3%82%A2%E3%83%97%E3%83%ADTV)（解説動画は章ごとに順次公開）

## リポジトリの使い方

このリポジトリは、書籍の章ごとに区切ったGitブランチ（`chapter-01`、`chapter-02`、…、`chapter-12`）としてサンプルコードを管理しています。

途中の章から読み始めたい場合や、手元の実装と見比べたい場合は、対応する章のブランチをチェックアウトすれば、その章の終わり時点の「動く状態」をそのまま確認できます。

```bash
git clone git@github.com:it-for-survivor/shape-survivor-for-hands-on.git
cd shape-survivor-for-hands-on
git checkout chapter-01
```

## 事前準備

1. [Godot公式サイト](https://godotengine.org/)から Godot 4.7 以降をダウンロードしてインストールする
2. Godotを起動し、「新規プロジェクト」を作成する（レンダラーは `互換性` を選択。低スペック環境でも動きやすく、今回の題材には十分）
3. プロジェクト名は自由（本書では `Shape Survivor` とする）

エディタの画面構成やシグナル・保存の作法など、細かい進め方は書籍本文を参照してください。
